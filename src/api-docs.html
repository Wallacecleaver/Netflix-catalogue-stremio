Points d'accès universels

Utilisables depuis n'importe quel serveur, addon, site web, bot ou script disposant d'une clé API sdb_….

URL de base du serveur (Fédération & Addons)
Les clients Stockage DB et addons compatibles ajoutent automatiquement /api/v1
URL complète de l'API (Clients REST / Applications)
Point d'entrée JSON universel (CORS activé · découverte auto sur GET /api/v1)
Endpoint lecture universelle (ID IMDb, TMDB, Netflix, Stremio ou Titre)
Accepte tt13016388, tt13016388:2:1, tmdb:95396, 81944880 ou ?title=Severance
Endpoint contribution / ajout de flux vidéo
Header : Authorization: Bearer VOTRE_CLE_API (nécessite une clé avec droit d'ajout)
Authentification universelle acceptée partout : Authorization: Bearer <clé> · X-API-Key: <clé> · Api-Key: <clé> · ou paramètre URL ?apikey=<clé>.

Référence complète des routes

    
Toutes les réponses sont au format JSON UTF-8 avec en-têtes X-RateLimit-* et X-Response-Time.


    

      

        
          

            Méthode
            Endpoint
            Description & Paramètres
          

        
        
          

            GET
            /api/v1
            Découverte automatique de l'instance (version, endpoints disponibles, méthodes d'authentification).
          

          

            GET
            /api/v1/status
            Statut de l'instance, nombre de titres couverts et capacités actives.
          

          

            GET
            /api/v1/trailers/:id
            Récupération universelle en chemin direct : accepte tt13016388, tt13016388:2:1 (extrait automatiquement la saison 2), tmdb:95396 ou nflx:81944880.
          

          

            GET
            /api/v1/trailers
            Recherche par paramètres : id, imdb, tmdb, netflix, ou title (+ year, type=movie|series, season, strict_season=1, fast=1).
          

          

            POST
            /api/v1/trailers/batch
            Récupération groupée jusqu'à 25 titres en un seul appel : {"items": [{"id": "tt13016388:2:1"}, {"title": "Dune", "year": 2021}]}.
          

          

            POST
            /api/v1/prewarm
            Préchauffage asynchrone (202 Accepted) jusqu'à 50 titres en arrière-plan.
          

          

            GET
            /api/v1/search
            Recherche dans le catalogue local : ?q=Severance&type=series&limit=20.
          

          

            GET
            /api/v1/title/:id
            Fiche complète (synopsis, affiche, genres, identifiants croisés, saisons et bandes-annonces).
          

          

            POST
            /api/v1/trailers/submit
            Ajoute un flux MP4 ou HLS (.m3u8) sur un titre ({"imdb":"tt...","title":"Saison 2 VF","url":"https://..."}) — clé avec droit d'écriture requise.
